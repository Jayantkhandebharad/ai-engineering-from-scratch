# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Read this first

[`AGENTS.md`](AGENTS.md) is the canonical operating manual for this repo — hard rules, lesson contract, per-PR validation, conflict resolution, new-lesson onboarding. Read it before opening a PR. The notes below are a quick orientation, not a replacement.

## What this repo is

A curriculum, not a SaaS app. 503 lessons across 20 phases (Python, TypeScript, Rust, Julia). The lessons *are* the product — every rule exists to keep them coherent at scale. The "Build It / Use It" split is the spine: implement each algorithm from raw math first, then run the same operation through a production library.

## Architecture at a glance

- **`phases/NN-phase-slug/MM-lesson-slug/`** — every lesson is a self-contained directory with `docs/en.md`, `code/` (+ `code/tests/`), `quiz.json`, and (optional) `outputs/` for the reusable artifact the lesson ships (prompt / skill / agent / MCP server).
- **`site/build.js`** is the static-site generator. It parses `README.md`, `ROADMAP.md`, and `glossary/terms.md` into `site/data.js`. The parser is structural — phase headers, the `| # | Lesson | Type | Lang |` table shape, and ROADMAP status glyphs (`✅` `🚧` `⬚`) all key off exact patterns documented in [`CONTRIBUTING.md`](CONTRIBUTING.md). Touch those files carefully.
- **`scripts/`** — Python automation. `audit_lessons.py` is the CI blocker; `build_catalog.py` produces the (gitignored) `catalog.json`; `check_readme_counts.py` keeps README lesson counts in sync; `link_check.py` validates links; `lesson_run.py` / `scaffold_workbench.py` / `scaffold-lesson.sh` help author lessons; `install_skills.py` installs lesson-shipped skills locally.
- **CI (`.github/workflows/curriculum.yml`)** auto-heals two things on push to `main`: README lesson counts and `site/data.js`. Never hand-edit either in your PR — leave them to the bots.

## Commands you'll actually run

```bash
# Validate before every push (audit is the CI blocker):
python3 scripts/audit_lessons.py
python3 scripts/check_readme_counts.py        # advisory; main self-heals

# Per touched lesson:
cd phases/NN-phase/MM-lesson/code
python3 main.py && python3 -m unittest discover tests -v
# TypeScript:  npx tsx main.ts && npx tsx --test tests
# Rust:        rustc --edition 2021 main.rs && ./main
# Julia:       julia main.jl

# Scaffold a new lesson:
./scripts/scaffold-lesson.sh NN-phase MM-new-lesson
# or: python3 scripts/scaffold_workbench.py

# Rebuild the site locally (only needed when debugging the parser):
node site/build.js
```

Python lessons depend on `requirements.txt` (numpy, torch, transformers, etc.). TypeScript lessons are Node 20+ with the allowlist in `AGENTS.md` (`hono`, `zod`, `ws`, `@hono/node-server`). Rust is stdlib-only, single file. Julia uses its stdlib.

## Rules that bite

These are the ones you will get wrong by default — re-read [`AGENTS.md`](AGENTS.md) for the full list with rationale.

- **One commit per lesson directory.** A 10-lesson PR is 10 commits. Subject: `feat(phase-NN/MM): <slug>`, ≤72 chars.
- **Every fenced code block needs a language tag** (`text`, `json`, `python`, `typescript`, `rust`, `julia`, `bash`, `console`, `mermaid`, `yaml`). The audit will fail otherwise.
- **Mermaid or SVG only** for diagrams. No ASCII / Unicode box-drawing.
- **Original implementations only.** Don't cite external curriculum repos; cite RFCs, specs, and papers when they're the canonical source.
- **Dependency allowlist is enforced.** If a finding suggests a banned dep, skip it with: *"stays stdlib-first for educational clarity."*
- **Never commit generated files.** `catalog.json` is gitignored; `site/data.js` is regenerated by CI on merge to main; `package-lock.json` is never tracked.
- **`quiz.json` is exactly 6 questions** (1 `pre`, 3 `check`, 2 `post`), `correct` is zero-indexed. Legacy `q/choices/answer` shapes crash the site renderer silently.
- **You handle by hand:** README lesson-link rows (the parser needs the `[Title](phases/NN-...)` markdown link to derive the URL), ROADMAP status updates, and `glossary/terms.md` when a term is used by more than one lesson.
